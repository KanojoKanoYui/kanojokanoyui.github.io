# 素材资源目录

这里登记网站使用的外部图片、字体、音效等素材及其授权信息。**没有记录在清单中的外部素材，不应直接加入网站或发布。**

## 当前目录

- `asset-credits.csv`：外部素材登记表模板。
- `../assets/`：站点图片资源；目前已有的 `yui-portrait.svg`、`yui-scene.svg`、`yui-window.svg`、`yui-lease.svg`、`yui-swap.svg` 和 `favicon.svg` 是本仓库内创作的原创 SVG，不是从 Pixiv 等平台下载的素材。其中 `yui-lease.svg`（租借契约场景）与 `yui-swap.svg`（身份改写场景）受《彼女、お借りします》《お兄ちゃんはおしまい！》的**题材氛围启发**而原创绘制，未复制任何上述作品的美术资产、角色设计或商标图形。

## 选材规则

1. 优先采用明确标注 **CC0 / 公共领域** 的素材；其次考虑许可清晰且适合本站用途的 CC BY 素材，并完整署名。
2. **“非商业”不等于免版权或可随意转载。** CC BY-NC 等许可通常限制商业用途；个人作品集、广告、捐赠/赞助、付费功能或未来变现是否符合许可，须结合实际用途判断。无法确定时不使用，联系权利人取得书面许可。
3. Pixiv 等创作平台上的作品受著作权保护。没有明确许可时，不下载后复制进仓库、不镜像、不改作、不裁切、不用作社交预览或网站装饰。仅能在平台规则允许且作者许可的范围内链接原作品。
4. 逐件检查肖像/隐私、商标、角色/IP、字体、模型或摄影对象的权利；图片许可不一定覆盖这些权利。
5. 保存检索日期和许可原文/截图或存档链接。若许可页面不可访问、表述含糊、授权主体不明或仅有“请勿商用”等模糊说明，先不使用。
6. 不以来源平台的搜索过滤器、作者未反对或他人转载作为授权依据。

## 新素材登记流程

1. 从来源页面逐项确认许可和权利要求。
2. 将通过审核的文件放入 `assets/external/`，采用描述性文件名，不覆盖原创文件。
3. 在 `asset-credits.csv` 补齐所有字段；如需署名，在站点可见位置展示。
4. 保留原始文件和许可记录；改作时记录修改内容。删除或替换素材时同步更新登记表。

当前没有经核验并收录的外部素材。为避免未经授权转载，本次仅建立资源目录与审核清单，没有从 Pixiv 或其他平台下载作品。
